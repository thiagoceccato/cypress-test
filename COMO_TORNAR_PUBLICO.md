# 🔓 Como Tornar o Repositório Público no GitHub

## 🎯 Objetivo
Tornar o repositório `cypress-test` público para que o diretor possa acessar o README sem precisar fazer login.

---

## 📋 Método 1: Via Navegador (Mais Fácil) ⭐

### Passo 1: Acesse o Repositório
1. Abra seu navegador
2. Vá para: `https://github.com/thiagoceccato/cypress-test`
3. **Faça login** na sua conta GitHub (se não estiver logado)

### Passo 2: Acesse as Configurações
1. No topo do repositório, clique na aba **"Settings"** (Configurações)
   - Está na barra de navegação horizontal, ao lado de "Code", "Issues", "Pull requests", etc.

### Passo 3: Encontre a Seção "Danger Zone"
1. Role a página até o final
2. Procure pela seção **"Danger Zone"** (Zona de Perigo)
   - Geralmente está no final da página de Settings
   - Tem um fundo laranja/vermelho para chamar atenção

### Passo 4: Alterar Visibilidade
1. Dentro da "Danger Zone", encontre o botão **"Change visibility"** (Alterar visibilidade)
2. Clique nele
3. Uma janela modal aparecerá

### Passo 5: Tornar Público
1. Na janela que abrir, você verá opções:
   - **Make private** (Tornar privado)
   - **Make public** (Tornar público) ← **ESCOLHA ESTA**
2. Clique em **"Make public"**

### Passo 6: Confirmar
1. Uma nova janela pedirá confirmação
2. Digite o nome do repositório: `thiagoceccato/cypress-test`
   - Ou apenas: `cypress-test`
3. Clique em **"I understand, change repository visibility"**
   - Ou "Eu entendo, alterar visibilidade do repositório"

### Passo 7: Verificar
1. Volte para a página principal do repositório
2. Você verá um badge **"Public"** ao lado do nome
3. Teste acessando o link no modo anônimo:
   ```
   https://github.com/thiagoceccato/cypress-test
   ```

1. Continue a partir do **Passo 2** do Método 1 acima

## 🆘 Problemas Comuns

### "Não encontro a opção Change visibility"
- **Solução**: Certifique-se de estar na aba **Settings**
- Role até o final da página
- Procure pela seção "Danger Zone" (fundo laranja/vermelho)

### "Preciso de permissões de administrador"
- **Solução**: Você precisa ser o **owner** do repositório
- Se for um fork ou não tiver permissões, peça ao owner para tornar público

### "Não consigo fazer login"
- **Solução**: Verifique suas credenciais
- Ou use o GitHub Desktop para abrir no navegador
